# AI 시황노트

평일 아침 Claude 예약 작업이 이 폴더에 마크다운 노트를 올리면, 자동 갱신(`build_notes.py`)이 `data/notes.json`으로 모아 홈페이지 'AI 시황노트'에 보여 줍니다.

- 파일 이름: `YYYY-MM-DD-종류.md` — 종류는 `morning`(아침 시황), `close`(장마감), `earnings`(실적 해설), `research`(리서치 요약), `weekly`(주간)
- 첫 줄은 `# 제목`, 그다음부터 본문
- 본문에서 쓰는 표기: `## 소제목`, `- 목록`, `**굵게**`, `[글](https://주소)`
- 숫자에는 출처와 기준 시각을 함께 적고, 매수·매도 권유 문구는 쓰지 않습니다.
